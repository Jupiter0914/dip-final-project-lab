# 图件的输入与复现

在正式计时、统计及编码归档全部完成后，从项目根目录运行 `python -X utf8 -m poly04.figures confirm`。默认读取冻结清单、results/poly04/confirm 和 local/poly04/confirm/outputs.zip，将图件写入 results/poly04/confirm/figures。若审核包中归档位于其他位置，可用 --archive 指定文件；--output 可写入新目录。程序对照实验收据核验整个 ZIP，并核对图中每个编码文件的 SHA-256、尺寸和重新解码后的全图错分。

primary-source-sessions.png 分来源展示主条件的 R≥2 源均值、三个会话和删除单个源的敏感性。源级图中的一个点对应一份原始蒙版。误差线表示配对 95% 区间；删除单个源或类别的线表示实际均值范围。外域类别的重抽和删除只包含实际进入共同成功多圈分析的类别。

delivery-and-baselines.png 左图是全体预定源的输出率，右图是跨圈输出相对各对照在共同成功多圈源上的错分差。图中保留共同源分母。coverage-by-rate.png 单列各预算和时点的全源交付率，标题给出该补充条件实际安排的原始源数。

cases-Oxford.png 与 cases-LEMS.png 分别使用冻结分析选出的典型正增量、最接近零、最低增量和结构诊断。相同一对实际文件可合并为同一行并保留选择原因。结构冲突案例优先呈现全图少错、局部参考覆盖下降的小部件（预登记小区域为 1–64 原像素）。若没有这样的冲突，依照全体成功输出中最低的已观察结构面积比作独立说明，不由此推断跨圈造成退化。图中每个部件/孔覆盖与面积从该次两份真实 PM31 的实际身份映射重新计算。参考图附局部位置，后两图采用同坐标、最近邻放大；FP/FN 与质量仍来自全画布。在已有预登记 paired_summary 极值与 regions_cases 绝对最差记录中，如有与主案例不同的最大改善源或面积比严格小于 0.5 的结构，会于 cases-additional 图中单列为附例。主案例始终保留冻结选中的原始源和实际重复，即使代表调用恰好持平而源均值改善。figure-cases.csv 保存每行源、会话、重复、方法、文件哈希、裁片坐标及结构数值。
