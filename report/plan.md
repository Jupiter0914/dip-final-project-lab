# 正式实验与 Word 写作安排

## 一周内的工作量

| 日程 | 工作、实验单位与产物 | 预计用时 |
|---|---|---|
| 第 1 天，已完成 | 四个候选、查新、两个开发原型、淘汰 B、冻结 A 并完成 100 张独立确认和可复算审核包 | 真实运行日志见 results 下的 run.json |
| 第 2 天 | 审核现有结果。预先写出正式扩展清单及新图哈希。取确认组所用 25 个品种的官方 test 额外 8 张/品种，依相同哈希次序跳过已用 136 图和字节重复，预计 200 张。锁定 16/32 点主表，另外登记 12/24/48 点的率失真曲线，单独标为新增预算 | 约 2–3 小时，含配置和复现检查 |
| 第 3 天 | 运行新 200 张固定比较。把全点 DP、相同搜索的几何目标、回填目标保留在同一运行。另保存原始标签、标准化外形、组成部件数与细枝/凹口示例。按图与按品种复算区间 | 原两档七路约 124 秒，额外三档先用开发图测速。为复核和可视化留 2–3 小时 |
| 第 4 天 | 按预先定义的边界复杂度和面积分层；补 1/2/3 像素容差下的边界曲线、原标签敏感性、误填位置和时间分布。若 DAVIS 2016 标注成功获取，可加独立视频序列迁移实验，每条序列固定一帧，单列报告。已核对官方下载页，本轮未取得 DAVIS 归档 | 本机 CPU 可完成主计划。外部验证放在 0.5 天内，获取失败就保留已验证物种范围。[DAVIS 发布页](https://davischallenge.org/davis2016/code.html) |
| 第 5、6 天 | 撰写最终 Word，完成算法伪码、误差公式推导、主表、率失真图与反例。检查图注、参考文献和实验复算说明 | 保留两个完整写作日 |
| 第 7 天 | 用新检出与审核包各复算一次，核对逐图 CSV 与正文数字并排版检查，演练 3–5 分钟答辩 | 半天复核与答辩准备 |

正式扩展保持现有确认结果及原始文件。若调整核心方法，以开发数据立项并给修改版另选真正未使用的留出内容。新 200 张共享部分品种类别，能扩展图像样本量；跨数据集结论取决于独立取得的外部标注。16/32 点的实测从 36 张 21.33 s 到 100 张 61.78 s，按确认速度线性估算 200 张 123.56 s；48 点全点 DP 的时间和长轮廓内存另测。大规模训练与新增付费算力均无需求。

## 实际核对的教学材料

- 本机《Chapter 8 Image Compression.pdf》第 2–3、5–7 页讲冗余、编码/解码、压缩比、原图与重建图的像素误差。第 7 页已渲染核对。这里的实际码长为 10+4K 字节，二值图的平方差和恰为误填数。
- 本机《Chapter 9 Morphological Image Processing.pdf》第 37 页 §9.4 讲连通分量。实验由确定前景提取最大外轮廓，边界 F 用一次二值腐蚀剥离内部像素，再在固定距离内配对。
- 本机《1 Digital Image Processing Using Matlab（英文）.pdf》第 11 章 Representation and Description，纸书第 438–439 页对应本机扫描 PDF 第 252 页，已渲染核对。图 11.2 展示提边、采样和连线，第 439 页开始 §11.2.2 的最小周长多边形近似。本项目采用固定点数与实际回填误差两项约束。
- 本机《Chapter 10 Image Segmentation.pdf》第 36–44 页讲全局阈值、Otsu，第 51 页进入局部统计阈值。可用于解释候选 B、D 的备选缘由。查阅路径为 D:/崇新学堂/大三上/数字图像处理/For students/ 下的课件和教材电子版。

| 章节 | 写作要回答的问题 | 已有或待补图表 |
|---|---|---|
| 1 场景与评价对象 | 已有蒙版如何变成紧凑、可编辑的轮廓？什么输入超出单圈格式？ | 现有 vertices.png；补一个有孔或多部件的输入与标准化目标 |
| 2 课程原理与现有方法 | 边界表示、固定字节数和二值误差有什么关系？已有顶点移动和区域目标做到哪一步？ | 教材页码与 research.md，补二维格点推导图 |
| 3 编码与改动 | 为什么在同一起点上改用解码后的 FP+FN？如何避免自交与重复顶点？ | src/method.py、字节表、4–8 行伪代码及一次试探移动 |
| 4 数据与冻结设计 | 源图/品种如何隔离？怎样调基线、选主指标并计入编码成本？ | samples.csv、freeze.md、试验顺序图 |
| 5 结果与消融 | 同字节能省下多少错分？哪些图退化？边界、时间和内存怎样变化？ | paired-gains.png、cases.png、逐图明细与统计表；补多个 K 的率失真曲线 |

| 附录 | 验证人员怎样从文件独立复算？工具辅助在哪些步骤使用？ | 软件版本、命令、冻结及交付提交、Release 哈希 |
