# POLY02 确认前冻结

旧 100 张是已知证据。本轮只使用旧 36 张官方 trainval 开发；用已有确认品种的其他官方 test 图像取 25×8=200，每个品种按 v1 哈希顺序跳过旧 136 个 ID 和重复文件。跨域只用作者 RAR 的 MPEG_7_resize，每个类别按独立哈希顺序取 1 张，共 70 类。排除两个索引 GIF 与预留的三个格式检查文件。LEMS 文件在原包中，本轮不参与统计。通过冻结前仅以成员名与字节哈希登记新样本，未运行编码与评分。

## 实现与固定选择

所有方法只接收相同原尺寸已知二值外圈。Oxford 标签 1 为确定前景；MPEG GIF 使用作者 myImRead 的上边、左边、右边中值规则确定背景。8 连通前景、4 连通背景的孔洞数、原始与标准化差异计入每行。边界是从掩模剥除 3×3 腐蚀内部得到的一像素带，容差按欧氏距离。输出保留单一简单环、整数原生坐标、共同 LINE_8 与 POL1，全程编码包含公共预处理、几何起点、后处理及序列化。

局部 XOR 与 IoU 均从 v1 固定切点的 8K 网格 DP 出发，步长 8/4/2/1/4/2/1，每轮正反交替，八邻域试探方向和并列顺序固定。IoU 用交集与并集的精确有理数比较。SM 是独立实现，优先 RDP 50 点，对扩展预算取 max(50,K+1)，以可用轮廓采样数为上限且必须多于 K；每轮枚举所有单删，在合法候选中选择最大回填 IoU，并列取当前环中最小下标。日志保留实际起点数、合法性退回及运行失败。几何基线把相邻原轮廓弧段固定归给对应边，使用到无限延长直线的平方垂距和。RDP 使用的是到有限线段的距离。

两个后处理都完整重做同一几何细调，再按相同七次扫描减小 XOR。带保护版本只接受候选 BF2 ≥ 该图该 K 的初始几何 BF2，精确分数交叉比较；允许零次移动。开发时已观察到严格下限仍保留实质区域收益，未搜索松弛阈值。全点 DP 需要 O(K n²) 时间和 O(n²) 内存。程序按实际 K 核对采样数，贪心插点失败表示本次搜索没有找到解。Windows 的峰值工作集与结束 RSS 分字段。

## 选择依据与判定

36 图结果显示，直接 XOR 与直接 IoU 的相对错分差均值约 −0.10%，95% 区间约 −0.43% 至 +0.23%。选择 local_iou 为最接近的区域比较对象。post_guard 相对 geometry 的错分在 K16/32 分别减少 6.34% / 7.12%，BF2 无退化；post_xor 减少 7.08% / 7.79%，两档分别 14/36、18/36 次 BF2 退化。保留严格保护及无保护消融进入新确认。开发中直接 IoU 与 XOR 的平均接近不构成专属算法优势。

主判定面向 200 张 Oxford 新照片。每张在两档内先平均，相对 geometry 的错误降幅至少 4%，配对区间下限为正，两档均有正收益；400 个逐图预算中 XOR 和 BF2 均不劣于几何起点。保护须至少保留无保护平均区域收益的 80%，相对 local_iou 的 IoU 差的配对 95% 下限不得低于 −0.10 个百分点，编码 p95 不超过 150 ms。无保护确实出现过边界退化才有保护的实践意义。直接 XOR 与 IoU 的等效范围、案例规则和所有阈值见 protocol.json。未通过即如实下调贡献定位。MPEG 外部验证单独解释，不计入 Oxford 的通过判定。

参数、代码、清单和旧依赖按 LF 规范化计算 SHA-256。先推送 poly02-freeze-v1 并回读，再运行新 Oxford、外域与补充预算。按照片或外部类别的单图为单位配对重抽 10,000 次。本轮无重新训练。PSO 是单独的固定开发代表组，三随机种子均保留；它的 27 次开发运行不会当作 27 张独立确认照片。
