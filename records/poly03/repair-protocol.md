# 完整蒙版开发后续诊断

首轮 32 张已知图在三个主预算加两个结构丰富的补充图档中，有 95 个超过表示下界的图像预算。独立最小逐圈 XOR 的 DP 有 6 个组合未通过结构要求。原候选池按逐圈和选出的首个合法解与全图打分选出的最优解在 93 个成功组合上逐字节一致。以下为看过上述开发结果后登记的同域机制诊断，沿用同一候选近似器、实际点数、码长与结构判据。

考察值得花检查预算的问题：如何为不合法的 DP 组合找到可行分配。两法先验证独立 DP。控制方法按逐圈误差精确枚举次优分配，在首次结构合法时停下。试验方法尝试把一个选定圈放入其他圈都保持高精度的参照环境，以实际完整回填和同一结构对应检查确定可疑的 (圈,点数) 选择，临时屏蔽后再做 DP；若定位失败，回到未屏蔽的次优分配流。此屏蔽只是寻找解的启发式，不能证明该选择在其他组合中绝对不可行。

初始组合通过时两种方法立即返回。每个方法最多使用 64 次完整结构 oracle（含初次、原始精度背景诊断、最终组合）。高精度其余圈只用于编码端询问原因，最终输出仍须恰好使用同一目标点数。角点及局部曲线计算、分配排序、全部检查与真实文件导出计时。保留成功数、与排序替代相同解数、额外错分、失败和计算量。该开发诊断仅有六个需要触发的组合，不据此宣布一般性优势。
