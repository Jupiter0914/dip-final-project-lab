# 全供点与全受点边诊断

在广域停止点测量完成并得到 72 个无严格改善的结果后，追加可复算成本核查。先以原规则重建各图的六供点、六受点边提议池，量出独立最低删除代价、最大单独插点收益及所有已保留成对操作的最小实际 XOR 变化。再从 36 张已知开发图的 32 点停滞状态，按最低删除代价、图像 ID 依次选第一张。入选仅作结构诊断，保留其他测量的完整分母。

该图对每一个供点、每一条不与之相邻的受点边枚举全轮廓原始整数坐标（允许来自其他弧），另加参考点到弦的半程位置以及弦上 1/8–7/8 处的双侧法向位置。法向偏移含 0、正负 1–8、12、16、24、32 原像素。去掉与最终保留顶点重合的坐标；只被删掉的供点本身仍可作为新坐标。每个最终环均真的完整回填后评分。保存每对供受位置最小误差、严格改善候选的简单性和 BF2 检查、最优实际坐标以及起点附近全部单点扫描表。若存在合格改善，保留原子操作前后顶点；若不存在，报告有限候选集和最小代价。该扩大范围的诊断不参与等资源方法排名。
