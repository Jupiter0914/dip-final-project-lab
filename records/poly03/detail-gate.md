# 具体位置保护的小试

在已登记的 36 张 Oxford 开发图上，BF2 版从三张不同品种的参考端枝上丢失达到连续长度标准的旧覆盖位置，触发本试验。使用相同的几何起点、原始 POL1、原八方向和七次步长扫描。五组为返回几何起点、无保护 XOR、原 BF2、BF2 加全局参考骨架召回底线、BF2 加具体参考骨架位置底线。后两组都保留相同的初始 BF2，各自只改变骨架约束。全局组要求覆盖的参考骨架点总数不低于初始值。具体位置组要求几何起点覆盖的每个参考骨架点继续被覆盖。两条规则均以初始集合为基准，允许颗粒级零动作。

不引入可调松弛量、训练或预测骨架损失。计算成本包含从原掩模提取外圈、几何起点、参考骨架、候选生成排序、实际整幅回填、合法性、BF2 与骨架判据和 POL1 编码。对照的几何与门控参数固定，完整时长是当前进程和并发环境的观测值。

除被保护位置外，另报参考细枝近旁 2 像素圆盘膨胀后的前景侧带，再去除全部骨架像素，统计其 FN 与位置得失。此侧带、参考凹口誤填、细颈的腐蚀连通半径、BF1/BF3 和区域 XOR 均没有用作新增门控。各条件在 72 个图像预算上汇总，再按源图配对。若具体位置只能让被检查的位置通过而缺少其他少丢细部的证据，降级为可选约束。
