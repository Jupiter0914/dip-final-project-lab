# 可行性诊断的简单替代

两种 64 次检查策略都只恢复原有六次 DP 拒绝中的四次。补一个同一问题的简单对照以定位剩余瓶颈：保持相同的 RDP 家族、总点数、父序和结构判据，只改变构造逐圈 RDP 层级前的循环起点。仅在原始独立 DP 被拒绝时触发。预定轮廓起点按源稠密环的弧长取 0/1/4/1/2/3/4 四个相位；每个相位按逐圈误差完整枚举次优组合，轮流各取一个。第一份合法即返回，全相位合计最多 64 次结构检查，逐圈曲线构建的额外时间全计。原始 DP 成功直接原样返回。

这项替代沿用六个已知触发组合，其余真实设置用原 DP 字节作为默认路径。它检验失败是否与近似候选的形状有关，不改变格式或宣布新方法已确认。看过结果后不继续扩相位或换数据。
