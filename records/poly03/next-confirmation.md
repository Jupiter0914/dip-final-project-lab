# 下一阶段确认方案（本轮未启动）

**拟冻结的问题。** 给定同一原始二值蒙版、完整结构对应、PM31 解码器、实际总码长和端到端编码时间，允许跨圈的顶点转移是否比只在各圈内部继续搜索带来可复现的额外收益？沿用“逐圈区域误差预排候选，最终整图验收”的最小实现。以按可加误差有序试配的 DP 做起点。保留 POLY02 单圈作为已经独立确认的稳定成果。单圈逃逸例和骨架位置保护作为解释性材料，暂不加入主算法。

**数据隔离。** 主控若同意，先按源照片/来源分组建新清单，再冻结 SHA、版本和分析脚本，最后才解码评分。Oxford 排除 v1、POLY02 和本包所有已看过的原照，之前用过的品种只能称新照片。计划以输入结构（简单、孔、多部件、近接）分层，每层约 20–25 个独立源，另设一项按自然分布汇总的权重说明。候选分层、图像读取用于查重而非调参。真实像素或文件 SHA 相同的样本排除，缩放、镜像及同源变体只进一个统计单位。无个体或拍摄会话标识时记录限制。

另一组优先考虑此前没有用于本研究评价的 LEMS 系列。先按文件族/类别做清单分配，保留原包来源，排除之前使用或可见的 Fish-a100、Building170 及其同源变体；若主张未见类别，则整个类别隔离。若改用 MPEG 已知 70 类的其他图，只报告新实例。LEMS 整包在 POLY02 获取过，本轮没有用其新图挑策略。

**比较、预算与失败。** 主条件暂定 256 字节，128/512 分列为码率敏感性；结构下界过高者仍进入覆盖率分母。在固定主机与进程条件下，100/200 ms 作为两个“已完成输出”观察点。提前登记最大候选数、轮数、提前退出及冷/热启动。主要对照包括纯按周长、独立 DP、按代价有序验证、精确整图评分、允许跨圈与仅圈内的可加预排、CGAL 两种原生代价。CGAL 保留多个新 worker 的结果和版本/历史，无数据依赖挑选最佳运行。结构对应、总字节、四类状态与本轮相同。

**主指标与决策。** 首先比较全体源的合格覆盖率与两法各自独有成功数，再在共同成功且实际同码长的源上比较时间内错分、IoU 和未用于筛选的 BF1/BF2/BF3。每张图先汇总重复计时与预算，在源层重抽，按结构分层另列，保留最差退化和无动作。独立数据若只重现格式支持，或跨圈对等时圈内搜索的差值小于运行间变动，就回到可行分配与结构验收的结论，不把小样机制扩展写成新的普遍优势。实际用途尚无人工编辑成本数据。实验证据不足时保留 POLY02 作为最终课程主结果。

**时间依据。** 本轮完整原型 32 图、三档及两个补充设置、两种官方 CGAL 原生代价在同机一次约 44–46 秒；100 图同量级结构约数分钟。时间门槛实验还要支付独立重复、候选审计和冷启动，应预留数小时进行采集、分层与复核。达到冻结决策前不撰写完整 Word。
