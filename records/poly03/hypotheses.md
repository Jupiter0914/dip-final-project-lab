# POLY03 开发问题登记

基点 cc2e60175acc1b2c07906551b71eb0905f8b1c7b。全部使用已知资料。本轮不打开任何新 Oxford、MPEG 或 LEMS 确认样本。完整蒙版从 POLY02 已经打开的 36+200 张 Oxford 和 70 个 MPEG 类别样本中，只按输入分层取 32 张；保留数据原身份与哈希。源图既往标记为 new 或 cross 的，在这里均作开发。各预算、源内部件均留在同一统计单位。

1. **完整蒙版假设。** 预算竞争可能要求将点从某条易近似的轮廓转到另一条复杂轮廓。对比按周长分配、同一逐圈近似器的独立误差曲线 DP、CGAL 联合几何删点。同码长下分别测独立分配的结构拒绝、逐圈 XOR 与组合 XOR 差值，以及两种分数在同一候选集中的排序差异。若误差可加且排序相同，完整渲染只作为可行性和交付验证。已有多对象预算 DP 与拓扑保持几何简化是直接先例。
2. **原子删插假设。** 一个共享操作同时删除一个顶点、在另一边插入一个点。只对最终同码长结果验证环和解码图。分别比较跨圈、同圈和两者；若收益归因于单圈重新放点或额外计算，则按实际来源表述。单圈额外试验以 POLY02 几何解的原始 BF2 作固定下限，尝试完整扫描停滞后的删插，和延长单点、多起点、随机及几何删插比较。
3. **细部诊断。** 在已知原图上用输入定义定位细枝、凹口及细颈。先判断全局 BF2 良好时是否存在可重复的位置损失，再决定是否保留最小保护试验。

初选 128 / 256 / 512 字节三档，含头部、每圈父编号和计数及全部坐标。输入清点显示两个真实样本有至少八条环。在批量计算各方法质量前为这类样本单列 1024 字节补充档，避免高结构下界只剩一个预算点。另报告有限表示下界、当前搜索失败、表示不支持、成功四类结果。开发探索以证伪为目的，不设置事后涨分阈值。后续冻结和新的独立确认另立工作包。
