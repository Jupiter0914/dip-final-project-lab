# POLY04 输入冻结前登记

本规则独立于编码与质量评价。候选来自 Oxford 官方 test 和 UPF 作者分发的 LEMS_ALL。主时点、方法、判定规则和最终样本精确 ID 另行冻结。本文件及 sampling.json 必须在首次成批打开新候选像素前随 Git 提交。数据流程仅读取输入与历史使用登记，输出掩模、来源清单、输入分层与排除原因。

**已知材料的口径。** records/samples.csv 给出 v1 的 36+100 张，POLY02 另增 200 张新 Oxford，合并共 336 个不同 ID。POLY02 的 70 个 MPEG 及 3 个预留格式检查名称（apple-1、bat-1、camel-1）均列入排除。两份原版 UPF 随包示例 Building170 和 Fish-a100 整族排除，后者确有 K4 MATLAB 试验。此前已查阅的 UPF 论文图示还含没有原始编号的轮廓，作为独立的可追溯视觉排除探针。另将 407 个计分用最大外圈目标、36 个 2× 最近邻尺度诊断目标逐一记录为已知派生视图，与其原始 ID 绑定。原包整体校验不等于其中每个形状都经人工查看或算法评价。已知表按源 ID 与文件哈希合并，分层筛过与真正逐图评过的阶段分别标注。

**源与外部类别。** 已检查的 LEMS 归档目录有 1462 个文件，只有类别和编号。全部 Fish-a（100）和 Building（243）排除，其余 1119 个编号来自 Container、FruitorVegetable、MiscAnml、Person、Robot、Toddler、Turtle。每类轮转，不把同一近重复簇的不同视图作为独立样本。连续编号有近似画面时从严合并。另令每个选中源在其类别内与已知同族/选中来源的编号距离至少为 3，作为未提供拍摄系列标签时的保守间隔；若有可识别的同形变体，跨编号、跨类别也合并。类别与可辨认文件族同时保留。数据未提供原始拍摄系列/物体身份映射，无法保证不同姿态的同一实物都可识别；100 指不同排重簇的形状代表。同类别中的新图只称新实例。若经冻结的排除与去重规则最终少于 100，锁定全部剩余族并报告不足，杜绝追加显著性样本。

**分层和去重。** Oxford 目标 200 个不同文件族，按完整输入在简单外形、孔、多部件、近接四层各取 50。近接优先分层；其余有孔、有多部件、简单依次处理。分层定义复用 poly03.full_data.descriptor。每个原生二值掩模保存输入字节 SHA、含尺寸和位序的规范像素 SHA，并作裁边、尺度归一化、镜像/旋转及近似轮廓比较。Oxford 另从官方 RGB 包检查同照指纹及可用 EXIF 身份字段。原作者的构建过程已专门排除显见的同宠重复图；发布包缺少完整的个体或会话索引。七个外部前缀是本次取样类别，并不保证此前从未在论文中见过相应语义类别。[Oxford 原论文 §2.1](https://cdn.iiit.ac.in/cdn/cvit.iiit.ac.in/ukieri/files_pubs/parkhi12a.pdf) · [Oxford 发布与署名](https://www.robots.ox.ac.uk/~vgg/data/pets/) · [LEMS 子集与论文图示](https://www.mdpi.com/1999-4893/17/1/25)

**完整执行顺序。** 固定规则和 SHA256 salt；合并原始文件、原始实例与教育示意图的已知登记；获准后只用输入生成近重复图并取传递闭包，优先排除所有触及已知材料的簇。按哈希选每簇唯一代表，Oxford 分层截额并以固定层序补位，LEMS 按冻结类别轮转，保留各层自然筛选计数。每个确认文件锁定原始 SHA、规范 SHA、family、category、stratum、来源成员位置及保留路径。抽取之后不得根据格式下界、搜索失败、计时或方法胜负剔除图像。分语料汇报，主分析使用实际生产高精度 R≥2，不能用统计重复或层数增加 N。严格规则会排除部分原本不同但轮廓相近的对象，评测适用范围随清单记录。
