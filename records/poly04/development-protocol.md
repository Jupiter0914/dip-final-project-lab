# POLY04 开发补查与新样本启用条件

2026-11-21 从已审核提交 8e05ef79dc8f4e15e54fdb57ad576a0dd86ed88f 建独立分支。开发只用 POLY03 已知的 32 张完整蒙版；其他旧记录仅用于已见清单和复核。确定性 PM31 结构与共同码长沿用 POLY03。

先比较历史圈内短表、充分同圈组合（禁三角/准三角）、历史跨圈、修正规则的跨圈、合法 DP 起点、原 CGAL squared 与从原 CGAL 出发的同一充分圈内后处理。时间从已解码原二值数组开始。方法独立完成初值或 CGAL 建网，无共享免费多边形。计算目标为 256 字节，100/200 ms 两个真实接收时刻；在相同轮数上另看候选数、接受数与两轮固定工作量。已知样本重复永不计为更多源图。

主候选是允许跨圈的搜索与同起点、充分的圈内搜索之差。开发时先看 R≥2 的共同可交付覆盖、平均错分差、胜平负与时限敏感性。圈内加强后若在 100 ms 已无任何有实际动机的优势，降级“跨圈有优势”的主张。仅在存在可证伪的具体问题时启用新清单：例如有跨圈可行的成对转移仍改善部分真实多环输入、能在开发资料中区分时间因素与动作范围，或具有明确预测的完整方法与现成强方法覆盖/质量权衡。开发结果若不支持单向优越，下一阶段可确认“是否还有额外收益”或已明确改写的完整方法问题。严禁更换指标以制造成功。

输入选择政策先单独提交。随后锁定逐源清单及代码、分析方法与重复策略，推送冻结标签后才运行新源的首个解码器质量实验。确认会话必须串行。不得按显著性追加源图。
