# POLY04 确认协议

## 唯一主问题和适用范围

在完整 PM31 结构对应、同一原始蒙版、同实际文件长度下，允许跨圈的搜索相对充分的圈内搜索，在 **Oxford、256 字节上限、调用方已收到的 100 ms、原始高精度环数 R≥2** 条件下能否平均少填错像素？主终点为同源、同会话、同重复的 XOR(within_full)−XOR(cross)。先在同一源的共同交付重复内平均，再对源均匀平均。其他预算、时点、数据域及 R=1 均不并入主数。全体输入统计到时覆盖率和五类观察状态。单部件或无孔不能事后排除出覆盖分母。

## 生产算法

四类内核状态、候选和调用方测时见 engine-methods.md。DP 初始化使用 POLY03 的单圈 RDP 误差曲线、可加总点数 DP，再在有限分配池中找首个完整验证通过者。候选池由 DP 与周长起点，以及两圈可枚举分配或多圈的 ±1/2/4 点转移构成，最多保留 40 组。它没有调用 repair.ordered_allocations 的精确次优队列。原版 CGAL squared 是独立的替代起点，目标是同一实际总点数。只有保持原环身份和原尺寸回填像素的方向修复和循环索引映射可以进入共同后处理。CGAL 失败时保留原坐标和状态，禁止回退到 DP。

删除和插入的单独评分只预排提案。充分圈内对照在所有同圈合法 donor/receiver 中按相同预评分精确取前 24；cross 在相同圈内及所有合法跨圈组合中取前 24。每个三角环仍可同圈对边替点，跨圈供体至少保留三点。对可加路径，每一整对删插的逐圈总误差需严格下降，之后实际重画整幅、要求真实 XOR 严格下降及矢量和数字结构正确。没有合格提案即停。受时限生产方法最多 8 次试探轮，轮开始前检查最大时限；已经开始的轮可晚到。历史固定工作量与开发补查只跑 2 轮，绝不混入限时主成绩。exact 补充采用相同候选直接按实际整图 XOR 排序，不加可加下降筛选。对预定 exact 子集的首次会话首次重复，从 seed、cross 与 exact 的已实际交付状态中（cross/exact 含相同起点）核查完整候选，计算真实可改但被可加筛选挡住的数目。该诊断在计时结束后执行。

## 数据、方法与时间

精确成员、原文件 SHA、原尺寸二值像素 SHA、族与结构分层按 samples.csv 锁定，见 data-selection.json、sampling.json。Oxford 为既有 336 张以外的官方测试照片；LEMS 排除旧例所在类别及近重复族。类别均衡或结构均衡的均值代表此评测分布。外部文件族是规范视图、编号和形状近重复规则得到的操作性代理，未获全面实物个体元数据。

全部新输入在 256 字节运行 seed、within_full、cross、cgal_within、cgal，每次同一轮同时观察 100 与 200 ms。128 和 512 字节的预登记补充实验仅使用每来源各 24 个已锁定的分层代表，同样 5 法和两时点。上述补充源在 256 字节另跑 exact。所有方法端到端真实执行，未共享计时内的几何起点/CGAL 求解。完整方法对照与跨圈机制本身分别分析。

3 个独立 Python/CGAL 进程会话，每个会话内 2 次重复，所有正式计算串行。每次启动都从同一已知 warm_id 预热，CGAL 的第一冷启动单列，之后原版 worker 在会话内常驻。输入已读入内存、规范为 0/1；源文件读取、哈希和掩模解码另计。研究入口开始到真实 PM31 字节序列化、同步调用接收器的首条取时、搜索实际结束、完整返回分别记录。调用方到达时间决定可用性；已序列化而尚未交付、或跨过截止的轮不能倒计。程序还记录原生证据归档、磁盘写入和超时时间。各源/预算块顺序按固定盐、会话、重复与身份散列。块内方法的哈希起始序列在各次重复轮换。精确盐、会话/重复编号、补充 ID 列表在 confirm.json。

## 分析与停止

按源配对 bootstrap 10,000 次，固定随机种子 40121。主效应 95% 区间下限为正、各会话均值均为正、删除任一源后均值仍为正，并要求全部 Oxford 输入的配对交付覆盖差 95% 下限至少 −2 个百分点（每 50 个输入最多约少交付 1 个为本轮容忍尺度），才记为 Oxford 稳定小增量。其余情况按完整方法有价值、增量未证实或基线相当/更好报告。共同成功是条件结果，缺失不填零。相对错分、零分母处理、逐源胜平负、极端值、所有重复都共同成功的敏感性和外部类别簇重抽/留一类均见 analysis-protocol.md。按相同源和算法次序校验 R=1 的负对照。单像素位置和高精度结构对应已经控制，BF1/BF2/BF3、每部件和孔的区域覆盖、精确率及缩水是评价量。这里没有 BF2 下限。

结构代价另量化同一 DP 银行下未经组合结构筛查的最低可加误差分配和最终合法起点的原尺寸 XOR 差，计入全部源/预算的状态、几何/数字拒绝和无合法文件。其含义限于该候选族和这一步。全局少错同时小结构缩水的冲突，按逐一匹配的参考身份评估，面积比 <0.5 为严重缩水，不据此另调方法。案例选择按统计协议预定。正式确认只按固定清单运行一次，所有不利结果保留。
